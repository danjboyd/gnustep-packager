# The About panel (branch about-dialog, a proposal)

Taken 2026-10-14 on private Xvfb displays. Left: libadwaita 1.7's
AdwAboutWindow (`Reference/AboutDialog/about_dialog.py`). Middle and right:
the theme's About panel, light and dark, with the header bar, for the same
options (name, developer, version, description, website, copyright and
licence).

The first page is AdwAboutWindow's: the icon at 128pt, the name in
title-1, the developer, the version in a pill. GNUstep has no navigation
pages, so the Details and Legal pages' contents follow inline, dimmed.
