# Monocypher

Monocypher 4.0.2 (https://monocypher.org), for checking update payloads'
Ed25519 signatures. `monocypher.c`/`.h` are from `src/`, and
`monocypher-ed25519.c`/`.h` (Ed25519 with SHA-512, as RFC 8032 and Sparkle
use) from `src/optional/`, unchanged. Release tarball
`monocypher-4.0.2.tar.gz`, SHA-256
`38d07179738c0c90677dba3ceb7a7b8496bcfea758ba1a53e803fed30ae0879c`
(the same from monocypher.org and the GitHub release). Licence: CC0, with
2-clause BSD as a fallback (`LICENCE.md`).
